# Getting Started with Elaichi

This guide provides technical instructions for compiling the Elaichi runtime from source, verifying the installation, and running programs.

---

## Toolchain Requirements

To compile the runtime, ensure the following dependencies are installed:

* **Rust Compiler**: `rustc` and `cargo` version 1.75.0 or higher.
* **Platform Linker**:
  * Windows: Microsoft C++ Build Tools (`link.exe`).
  * Linux: GNU Compiler Collection (`gcc`) or LLVM (`clang`).
  * macOS: Xcode Command Line Tools.

---

## Compilation and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikhil012N/elaichi.git
   cd elaichi
   ```

2. Build the release binary:
   ```bash
   cargo build --release
   ```

   The binary will be compiled to `target/release/elaichi` (or `target/release/elaichi.exe` on Windows).

3. Verify the installation:
   ```bash
   ./target/release/elaichi --version
   ```

## Executing Code

### CLI Syntax

```bash
elaichi run <path/to/file.el>
elaichi dump-ast <path/to/file.el>
```

### Example Application

Create a file named `app.el`:

```javascript
// Static function executing with raw registers
static function computeSum(n: i64): i64 {
    let acc: i64 = 0;
    for (let i in 0..n) {
        acc = acc + i;
    }
    return acc;
}

// Dynamic entry point
function main() {
    terminal.println("Starting application execution...");
    
    // Invoke static function across inter-stack bridge
    const total = computeSum(100);
    terminal.println("Accumulated total: " + total);

    // Dictionary initialization and mutation
    let state = {
        name: "Worker-1",
        processed: total,
        status: "idle"
    };

    state.status = "complete";
    terminal.println("State status: " + state.status);
    
    return 0;
}
```

Execute the program:

```bash
elaichi run app.el
```

## AST Bifurcation Inspection

To verify how the compiler routes routines to the static and dynamic stacks, run the `dump-ast` command:

```bash
elaichi dump-ast app.el
```

The output displays the segregated abstract syntax subtrees:
* **Static Functions**: Parsed parameter types, return signatures, and unboxed register instruction counts.
* **Dynamic Functions**: Dynamic local symbol tables and generated bytecode instruction sequences.
